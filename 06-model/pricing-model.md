# The Model · FinWise

> Module 6 · Pricing & Monetization. The pricing & packaging recommendation memo for FinWise.

## Stage + model

**Stage:** Stage 1 · Value Creation, FinWise has only 2% trial-to-paid conversion and 60% annual customer churn. These suggest users aren't consistently experiencing enough value to convert or stay. Before experimenting with pricing, FinWise needs to improve activation and retention.

**Model:** Subscription, Subscription provides predictable revenue, but users must experience ongoing value to justify paying. Moving to usage-based pricing could reduce initial commitment, but may make costs unpredictable for small business owners. I would retain subscriptions and focus on helping users experience value before asking them to pay.

_____

## Recommendation

Keep the reverse-trial subscription model, but introduce a value-based upgrade prompt for new users. Allow users to import financial data and create their first financial model before encouraging them to upgrade for continued access to advanced insights and forecasting.

**The pricing bet:** Packaging-to-value

_____

## Model signal

Targets successful financial data imports and first financial model completion. By allowing users to experience a meaningful financial insight before encountering the paywall, FinWise can improve activation and increase willingness to pay.
